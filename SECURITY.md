# Security / 安全

This is an experimental project. For a suspected vulnerability, use GitHub private vulnerability reporting if it is enabled on the published repository, or contact the maintainer at zmz04297@163.com. Do not put secrets, live session transcripts, or an unredacted exploit against a live target in a public issue. Include affected versions, a minimal synthetic reproduction, and impact.
